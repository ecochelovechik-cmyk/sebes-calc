# Калькулятор себестоимости

Считает себестоимость товара из Китая: юани → доставка по объёму → растаможка → сум за штуку.
Работает как приложение на телефоне, без интернета, ничего никуда не отправляет —
все данные остаются в телефоне.

## Формула

    себес $  = цена¥ ÷ курс¥/$ + СВМ_коробки × тариф$/м³ ÷ кол-во_в_коробке + растаможка
    себес сум = себес $ × курс_сума + доп_расходы

Эталон: 7¥ ÷ 6,67 + 0,24 × 110 ÷ 80 + 0,35 = **$1,7295 × 12 000 = 20 753,70 сум**

## Выгрузка в Excel

`.xlsx` собирается прямо в браузере, без сторонних библиотек — иначе приложение
не работало бы офлайн. Внутри обычный zip с xml; фото товара лежат в `xl/media`
и привязаны к ячейкам первого столбца.

## Грабли, на которые уже наступили

- **Без `<meta name="viewport">`** телефон рисует страницу шириной 980px и сжимает.
- **Самодельные кнопки-переключатели на iOS не срабатывают** — только родные
  `<input type="radio">` + `<label for>`.
- **Авторское `label { display:flex }` перебивает атрибут `hidden`** — нужно
  явное `[hidden] { display: none !important; }`.
- **Файл, разосланный людям, сам себя не обновляет.** Поэтому в подвале стоит
  дата версии, а раздавать лучше ссылку, а не файл.
