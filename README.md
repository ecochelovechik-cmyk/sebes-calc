# Калькулятор себестоимости — сервер

Публичная ссылка с калькулятором + сбор всех расчётов в одном месте.

- `/` — калькулятор, открыт всем по ссылке
- `/admin` — «Все расчёты», закрыто кодом `ADMIN_CODE`
- `/healthz` — проверка живости

## Развернуть на Railway

1. **Создать проект** → Deploy from GitHub repo → выбрать этот репозиторий.
2. **Variables** → добавить `ADMIN_CODE` = свой код администратора.
   Код нигде в файлах не хранится, только здесь.
3. **Volume** → создать и примонтировать в `/data`.
   Без этого база стирается при каждом передеплое.
4. **Settings → Networking → Generate Domain** — получите ссылку вида
   `имя-проекта.up.railway.app`. Её и раздавать людям.

Старт задан в `Procfile`, зависимости в `requirements.txt` — больше ничего не нужно.

## Локально

    ADMIN_CODE=любой-код python -m uvicorn server:app --reload

База ляжет в `sebes.db` рядом со скриптом.

## Данные

- `device` — телефоны, метки «Телефон 1, 2, 3…», переименовываются в админке.
- `calc` — расчёты. Итог пересчитывается на сервере по той же формуле,
  что и в браузере, чтобы в отчёт нельзя было прислать произвольную цифру.

Формула: `¥ ÷ курс$ + СВМ × тариф ÷ кол-во в коробке + растаможка`, затем `× курс сума + доп. расходы`.
